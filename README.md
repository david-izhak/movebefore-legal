# Move Before — legal documents

Public copies of the Privacy Policy and Terms of Service of the Move Before app for Android,
served by GitHub Pages:

- https://david-izhak.github.io/movebefore-legal/privacy-policy.html
- https://david-izhak.github.io/movebefore-legal/terms-of-service.html

Do not edit these files here. They are generated from the texts shipped inside the app by
`android-app/tools/sync_legal_site.py` in the app repository, so the published policy is always
the one the app shows.
